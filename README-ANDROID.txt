NIGERIA FIRST ELECTION MONITORING — CAPACITOR ANDROID PROJECT

This project wraps the Supabase-connected web app in a native Android shell using Capacitor.

REQUIREMENTS:
- Node.js 18 or newer
- npm
- Android Studio
- Android SDK and a configured Android device/emulator

BUILD STEPS:
1. Extract this ZIP.
2. Open a terminal in the extracted project folder.
3. Run:
     npm install
     npx cap add android
     npx cap sync android
     npx cap open android
4. In Android Studio, wait for Gradle sync to finish.
5. Choose Build > Build Bundle(s) / APK(s) > Build APK(s).
6. The debug APK will normally be located under:
     android/app/build/outputs/apk/debug/app-debug.apk

COMMAND-LINE BUILD:
- Windows:
     cd android
     gradlew.bat assembleDebug
- macOS/Linux:
     cd android
     ./gradlew assembleDebug

IMPORTANT:
- The android/ folder is generated by `npx cap add android`; it is not included in this starter ZIP.
- The Supabase publishable key is client-safe, but never put a service_role key in browser or APK code.
- The current app is a starter connected app. Before real election deployment, add strict RLS,
  role-based access, observer assignment, audit logs, duplicate/conflict handling, secure evidence
  uploads, offline queue synchronization, backups, and security testing.
- An APK is not automatically offline-capable merely because it is packaged with Capacitor.
  The app must implement local data storage and synchronization for reliable offline operation.


GITHUB ACTIONS BUILD:
1. Upload this project to a GitHub repository.
2. Make sure the default branch is named `main`.
3. Open the repository's Actions tab.
4. Select `Build Android APK`.
5. Click `Run workflow` if the workflow has not started automatically.
6. When the job finishes, open the completed workflow run.
7. Scroll to Artifacts and download:
   nigeria-first-election-monitoring-debug-apk
8. Extract the downloaded artifact ZIP to obtain app-debug.apk.
